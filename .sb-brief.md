# Task for Space bunny: polish Settings and Welcome (Athanor)

You are working in a git worktree of Athanor (a Tauri 2 + React + shadcn browser shell). Branch: `spacebunny/settings-polish`.

`app/src/components/page.tsx`. Do NOT touch the sidebar, App.tsx, Toolbar, Rust code, or any `e2e/` file (another agent is editing those).

Read `docs/HIG.md` first. It records the Apple Human Interface Guidelines rules this project follows. Apply them to the two screens:

1. **Copy**: button labels and menu-like items in Title Case without articles ("Check for Updates", "Reset Site Permissions"),
   an ellipsis only when the action needs more input. Descriptions stay sentence case, short, no trailing noise. Keep the UI language English.
2. **Accessibility**: every icon-only button/switch has an accessible name; form controls have labels; nothing smaller than
   `text-[0.7333rem]` (11 px); `aria-live` on status text that changes; focus order follows reading order. Do not rely on colour alone.
3. **Hierarchy and spacing**: consistent 8-pt rhythm (use the existing Tailwind spacing scale), related rows grouped, one prominent
   button per section at most, destructive actions last and styled `destructive`.
4. **Feedback**: after an action that changes something (reset, import, check for updates) the person sees a result near the control
   (text or toast) - add where missing, keep it brief.
5. **Consistency**: same wording for the same thing across Settings and Welcome (e.g. "Hardware acceleration", "Interface size").

Hard constraints:
- Do not change behaviour, setting keys, IPC calls, `data-part` / `aria-label` values that already exist (end-to-end tests select by them),
  or the DOM structure that `e2e/ui/*.cjs` relies on (`[data-part="welcome"]`, `footer button:has-text("Get started")`,
  `[role="radiogroup"][aria-label="Browser to import from"]`).
- Use only classes/components already used in the project (shadcn components under `app/src/components/ui`). No new dependencies.
- Sizes are in `rem` (the interface scales with a root font size); do not introduce `px` font sizes.

Verify before finishing (run from `app/`): `npm run typecheck` and `npm test` must pass.
